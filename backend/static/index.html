            AMI Standards & OBIS Identification System Reference
          

          
Official OBIS code registrations under IS 15959 (Parts 1-3) and IEC 62056-6-1 for smart meter interoperability.

        


        

          

            

              
              IS 15959 Companion Specification
            

            

              Mandated by CEA (Central Electricity Authority) and BIS for all Indian smart meter rollouts under the Revamped Distribution Sector Scheme (RDSS). It standardizes the data model, object definitions, and load survey capture periods (15/30 min).
            

            

              
• Part 1: AC Static Direct Connected Meters (up to 60A / 100A)

              
• Part 2: Transformer-Operated Static Watt-hour and Var-hour Meters

              
• Part 3: High Voltage Boundary and Feeder Metering

            

          


          

            

              
              IEC 61968-9 (CIM for Distribution)
            

            

              Defines the vendor-neutral message schemas for utility back-office enterprise integration. Translates meter measurements into canonical MeterReadings and grid alarms into standardized EndDeviceEvents.
            

            

              
• ReadingQuality: Valid, Missing, Estimated, Suspect

              
• EndDeviceEvent: Standard tamper, power quality, and outage codes

              
• IntervalBlocks: Time-series telemetry payloads
